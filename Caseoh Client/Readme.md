# 🧩 Caseoh Client - Minecraft Bedrock PVP Injector

Caseoh Client is a custom WPF launcher designed for injecting DLLs into **Minecraft Bedrock Edition (Windows/UWP)**.  
It features a modern UI, Discord Rich Presence, auto-detection of Minecraft, and manual DLL injection support.

---

## 📦 Features

- ✅ Sleek custom WPF UI with rounded corners and blur background  
- 🚀 Auto-launch Minecraft + auto-inject DLL  
- 🛠️ Manual DLL injector with file picker  
- 📁 Inject folder auto-created for your convenience  
- 🧠 Discord Rich Presence with clickable buttons  
- 🗂️ Dropdown to select from DLLs in the Inject folder  
- ⚙️ Launch options & settings (customizable)

---

## 🛠️ Setup

1. **Download & extract** the Caseoh Client files.

2. **Place your DLLs** in the `/Inject` folder  
   > 💡 This folder is automatically created the first time you launch the app.

3. **Run** `CaseohClient.exe` to open the launcher.

4. **Click** the **"Launch"** button to:
   - Start **Minecraft Bedrock Edition**
   - Automatically inject the **selected DLL**

5. **Right-click** the **"Launch"** button to:
   - Manually select a DLL using a file picker
   - Inject it after Minecraft opens
